## 2. AC-LIP: 영어 음성과 자연스러운 입모양

### 시험 입력과 공정성

1. 브랜드 승인 발음·통화·숫자·구성·조건으로 영어 대본을 작성한다. 시험용 가상 오퍼는 TEST 표시가 있는 비공개 입력으로 분리한다.
2. 음성 후보 2-3개를 같은 짧은 대본으로 먼저 비교한다. 영어 자연스러움·명료도·브랜드 발음·혜택 이해를 확인한 뒤 음성 한 개를 고정한다. 특정 TTS나 성우의 우위를 문서만으로 확정하지 않는다.
3. 최종 master WAV와 발화/자막 대본의 SHA-256 해시를 저장한다. 검증된 음원 파일을 립싱크 엔진에 전달한다. 완성 파일에서 별도 오디오 재생성·말속도 변경이 있으면 다시 평가한다.
4. 기본 이미지 비교: 동일 승인 portrait와 master audio를 HeyGen IV 및 Sync sync-3의 문서상 지원 경로에 전달한다. 2/pro에 정지 이미지를 넣지 않는다.
5. 실인물 원본이 확보된 경우에만 별도 비교: 동의 받은 촬영본에서 HeyGen eligible Digital Twin과 Sync 영상 경로를 만든다. 서로 다른 학습/입력 방식임을 표기한다. V는 `supported_api_engines`가 허용하는 look만 사용한다.

입력 제약·실시간 제품 구분의 근거는 [후보 조사](../review/shopee-ai-live_lipsync_research_v1.md)와 그 안의 공식 API 링크를 따른다. 새 계약/계정에서 사용 권한을 확인한다.

### 여섯 시험 장면

| 장면 | 제안 길이 | 주요 검증 |
| --- | ---: | --- |
| 브랜드·제품 인사 | 20초 | Banila Co / Clean It Zero 승인 발음, 웃음에서 말하기 전환 |
| 구성품 설명 | 15초 | 수량, 미니/본품, /p/·/b/·/m/ 입 닫힘 |
| 용량·선택 안내 | 25초 | 숫자·milliliters, 짧은 쉼과 마무리 |
| 가상 쿠폰 설명 | 35초 | 할인율·상한·최소금액·통화, 자막과 발화의 의미 일치 |
| 일반 FAQ | 30초 | /f/·/v/, 질문 후 억양, 과장되지 않은 답변 |
| 긴 연결 문장 | 45초 | 시작/중간/끝의 싱크, 얼굴 유지, 호흡·표정·시선 |

한 엔진의 기본 출력은 총 170초다. 두 엔진 한 번씩이면 340초 약 5.67분이다. 추가 take와 두 번째 입력 트랙은 별도 비용으로 계산한다. 길이는 대본 확정 후 바뀔 수 있고 변경된 합계를 기록한다.

### 합격 목표와 측정 방법

| 항목 | 제안 합격 기준 | 측정·보관 |
| --- | --- | --- |
| 중요한 발화·사실 | 브랜드 승인 발음, 숫자·통화·구성·조건의 중대한 오류 0건 | 브랜드 검수자 + 목표 시장 영어 검수자의 원음/자막/영상 비교. 타임코드 오류표 |
| 음성 자연스러움 | 블라인드 평가 평균 4.2/5 이상 | 평가자 5명, 최소 3명은 목표 시장 영어 사용자. 1=사용 불가, 3=이해되나 어색, 5=판매 진행자로 자연스러움 |
| 입모양 자연스러움 | 블라인드 평가 평균 4.2/5 이상 | 얼굴 전체를 정상 속도로 본 뒤 입 주변 확대. 공급사·파일 순서를 숨기고 무작위 재생 |
| 채택 의사 | 5명 중 4명 이상 채택 가능 | 광고·방송에 쓸 수 있는지 별도 yes/no. 점수만으로 대신하지 않음 |
| 시간 정렬 | 주요 발화 지점의 절대 A/V 오차 p95 80ms 이하를 초기 목표로 설정 | 평가자 두 명이 합의한 음향·입 닫힘/열림 기준점. clip당 5개 이상, 전체 30개 이상. p95는 작은 순서로 정렬한 오차의 95% 지점. 원본 fps와 frame 단위 분해능 기록 |
| 측정 불확실성 | 기준점 불일치 1frame 초과는 재검토 | /p/·/b/ release, /m/ closure 등 합의 가능한 지점 사용. 물리적 발음과 시각 변화 차이를 오차로 오인하지 않음. 합의 불가하면 통과로 계산하지 않음 |
| 시각적 중대 결함 | 얼굴 교체/입·치아 깜빡임/발화 중 입 정지/잘못된 컷 연결 0건 | 매 출력 전체 길이 검수, 오류 frame과 원본 저장. 평균 점수로 상쇄하지 않음 |
| 장면 끝 유지 | 시작·끝의 정렬 오차 차이 80ms 이하 목표 | 45초 장면에서 처음·끝 공통 기준점 비교. 최종 mux/편집 파일에서도 반복 |

80ms는 25fps에서 2frame이다. 30fps에서는 약 2.4frame이므로 실제 frame·timestamp 기준으로 기록한다. 자동 lip-sync 점수는 보조 정보로 쓰며 사람의 브랜드·사실·얼굴 검수를 대체하지 않는다.

최종 장면 길이는 15-35초를 기본으로 잡고 45초는 스트레스 시험용으로 쓴다. 긴 대본이 필요하면 문장과 호흡 경계로 나눈다. 파일 조각이 바뀌어도 호스트·목소리·피부 톤·빛·의상이 유지돼야 한다.

### 엔진 채택 기록

평가표, 입력/음성 해시, 대본·오퍼 버전, host/look/model ID, 생성 payload와 job ID, 채택 파일, 유료 생성 분량, 실패 이유를 보관한다. 다시 요청했을 때 생성 파일이 byte 단위로 같다는 보장은 하지 않는다. 선택 이유는 실제 품질, 재생성 비용, 허용 입력·권리·계정 제약을 묶어 적는다.

## 3. AC-FACT: 상품·프로모션·원본 증거

모든 사실은 해당 국가 storefront의 승인 데이터와 연결한다. 기존 KR/US 제품 인덱스는 탐색 자료이며 SEA 오퍼 원장으로 사용하지 않는다.

### 단위 검증: 데이터와 대본 규칙

| 시험 | 입력 | 기대 결과 |
| --- | --- | --- |
| 필수 필드·placeholder | SKU·국가·통화·구성 누락, `[ITEM_A]` 미해결 | 생성/제작 승인/편성 차단, 이유 기록 |
| 수치 의미 일치 | 자막 100mL / 발화 100 milliliters, 할인율·상한·최소금액 | 같은 의미면 통과. 하나라도 다르면 차단 |
| 비교 가격 | 단품과 세트의 용량·옵션·쿠폰·배송 기준 다름 | 절감액·할인율을 계산/발화하지 않음. 동등 조건이 확인될 때만 Decimal 등 정확한 금액 계산 |
| 효능·체험 표현 | 승인되지 않은 효능, AI 실제 사용 경험, 출처 없는 임상 수치 | 승인 목록 대조 실패. 검증된 정보로 수정 후 재심사 |
| 실제 원본 | source ID는 있으나 파일/권리/국가 claim 누락 | 시연 장면 차단. 해당 원본을 확보할 때까지 일반 구성 안내로 대체 |
| 오래된 미디어 | 유효기간이 지난 모델·음악·시연 권리 | 해당 파일 편성 불가 |
| 판매 불가 옵션 | 현재 pin 상품과 scene SKU/옵션 불일치 또는 재고 미확인 | 가격·CTA 장면 차단. 안전한 일반 안내로 전환 |
| 언어 정책 | 영어판으로 ID 라이브 배포 요청 | ID 승인·현지어 조건 미충족으로 공개 배포 차단 |

### 통합 검증: 한 장면의 네 가지 표현

매 장면에서 음성, 자막, 가격/혜택 카드, 실제 Shopee 상품 카드·옵션을 대조한다. 동일한 `offer_id/version`을 사용한다. 숫자를 말하는 장면은 음원에도 해당 오퍼 버전을 연결하고, 가격/쿠폰 변경 시 대판만 바꿔 재사용하지 않는다.

계정의 실제 상품 pin·voucher 확인은 기본적으로 운영자 콘솔로 수행한다. 공식 승인 연동이 확인된 경우에만 자동화 경로를 검증한다. mock 이벤트 시험이 Shopee API 접근 가능성의 증거가 되지 않는다.

오퍼의 예정 종료시각이 장면 끝보다 빠르면 재생을 시작하지 않는다. 원장 데이터 신선도 기준은 승인된 공급 경로의 실제 갱신 주기에 맞춰 정의하며, 조회 실패를 재고/가격 유지로 해석하지 않는다.

검증한 원본은 시작/종료 timecode와 출처를 보관한다. 발색·피부·제품 결과를 바꾸는 보정, 전후 컷 순서 변경, 필수 주석 잘림을 실패로 처리한다. 브랜드 원본이라는 사실과 해당 시장의 짧은 삽입 허용은 서로 다른 확인이다.

## 4. AC-SOAK: 24시간 내부 운전

**대상은 내부 재생/시험 송출이다. Shopee 공개 24시간 시험을 뜻하지 않는다.** 24편 × 6분 = 144분의 편집 콘텐츠를 열 개 편성표로 재구성하면 1,440분 = 24시간이다. 매번 재배치한다고 24시간의 고유 콘텐츠가 되지 않으며 공개 녹화 반복 제한을 해결하지 않는다.

### 정상 운전

- 입력: 제작 승인 파일, 시험 SKU/오퍼/claim 데이터, 허용 조건이 잠긴 국가·계정 상태, 내부 OBS/플레이어 또는 시험 sink.
- 측정: 24시간 연속 timeline, 현재 scene/SKU/offer ID, 장면 시작/끝, 파일 상태, 출력 fps·audio timestamp·문제 이벤트.
- 제안 출력 자산 기준: 세로 9:16, H.264/AAC, 48kHz 음성, 영상/자막/원본 공통 timeline. 1080×1920·30fps는 내부 master 후보 규격이다. 실제 Shopee 출력 규격·bitrate는 승인 계정 가이드와 테스트 후 결정한다.
- 0·6·12·18·24시간 지점에서 같은 기준 clip의 A/V offset을 확인한다. 누적 drift 100ms 초과 0회 목표. 일정한 지연과 시간이 지나며 늘어나는 지연을 구분한다.
- 2초 초과 black frame·의도하지 않은 무음·멈춤 0회 목표. 원본의 의도적 쉼/무음은 장면 metadata로 구분한다.
- 현재 scene과 pin 예정 SKU의 불일치 0건. 내부 시험에서는 콘솔 확인을 모의 입력해 동작을 검증하고, 실제 계정 일치는 공개 파일럿에서 따로 확인한다.

### 장애 주입과 기대 동작

| 강제 장애 | 제안 기대 동작·합격 기준 |
| --- | --- |

| 실행 중 가격·증정·재고의 중대 모순 감지 | 위험 대판·CTA와 해당 발화 차단, 2초 이내 안전한 일반 장면으로 전환 목표. 반응은 감지시각부터 측정하며 원천 변경을 실시간으로 모두 감지한다고 주장하지 않음 |
| 일반 편집 순서 변경 | 현재 유효한 장면은 35초 이내의 다음 안전 경계에서 교체 가능. 중대한 잘못된 혜택에 이 지연 기준을 쓰지 않음 |
| 오퍼 원장 조회 실패/신선도 초과 | 가격·쿠폰·재고 주장 장면 제외. 승인된 일반 상품/조건 확인 안내 또는 운영 중단. 오래된 값을 임의 유지하지 않음 |
| pin 예정 상품과 실제 상품 불일치 | CTA·혜택 장면 차단, 운영자 확인 후 재개. 가짜 클릭 영역으로 대신하지 않음 |
| 원본 파일 누락/손상 | 해당 증거 장면 제외, 시연을 예고하는 멘트도 함께 제거. 실제 playback 검사 |
| queue 중복·동일 FAQ 집중 | 같은 FAQ coalesce, 지정 cooldown 준수, 중요한 운영자 요청 우선. 숫자 목표는 파일럿 후 정하되 같은 응답 연속 재생을 시험 |
| 네트워크 단절 | 내부 시험 sink에서 감지·복구·안전 중단 기록. 공개 Live 재시작은 해당 계정의 승인 경로에서만 검증 |
| 생성 API timeout/retry | 같은 작업 retry는 idempotency로 중복 결제/채택 방지. 새 take는 별도 작업. 이미 검수된 방송 파일 재생은 생성 API 장애와 분리 |
| AI 형식/연동 승인 만료 또는 금지 전환 | 해당 국가 공개 출력 차단. 내부 라이브러리 QA와 파일 보관은 유지 |
| 운영자 takeover / stop | 2초 이내 위험 발화·오버레이 중단 목표. 복구는 유효 상태 재확인 후 |

운영자 콘솔 경로에서는 사람 반응시간도 별도 측정한다. 자동 경로가 없는 계정에서 2초 end-to-end 대응을 보장하지 않는다. 로컬 차단 지연·원천 데이터 갱신 지연·사람 확인 지연을 따로 보고한다.

모든 강제 장애가 기대 결과를 보이지 않으면 내부 운전 불합격이다. 정상 구간만 24시간 재생한 결과로 장애 대응 완료를 주장하지 않는다.

## 5. AC-LIVE: 국가·계정별 공개 파일럿

아래 확인이 완료된 실제 계정 한 곳에서만 진행한다. 최신 공식 가이드, 계정 화면, 승인 기록을 보관한다. 담당자에게 연락하거나 권한을 신청하는 작업은 이 계획 작성에 포함되지 않았다.

| 확인 | 필요한 증거 |
| --- | --- |
| 국가·계정·판매자 유형 | 실제 storefront, seller/affiliate/Mall 구분, 판매 권한 |
| AI·녹화 형식 | 현재 공식 정책과 해당 계정에 적용되는 승인 범위. 호스트, 모델, 영상, 캠페인, 표시, 실제 상호작용 조건 |
| 원본 데모 삽입 | 해당 국가의 허용 길이·빈도·호스트 화면 유지 방식. SG 등에 blanket 예외 가정 금지 |
| PC/OBS/RTMP | 실제 계정 허용 상태, server/key·수명, 승인된 output 규격. key는 로그에 평문 보관하지 않음 |
| 댓글/상품/쿠폰 동작 | 실제 허용 콘솔 또는 승인 integration. SG 금지된 자동 수집·조작 경로 제외 |
| 세션 종료·이어가기 | 최대 세션 길이, 종료/재시작·인계 규칙, 세션별 쿠폰·pin 재검증 |
| 사람 감독 | 모더레이터·운영자 근무표, takeover·알림·중단 경로. 심야 무응답 상태 방치 금지 |
| 콘텐츠 권리 | SEA/Shopee/상업 사용/모델·음성·음악/기간, 국가 승인 claim |

첫 공개 시험은 계정이 허용한 짧은 감독 세션으로 시작한다. 길이·횟수·24시간 확대는 실제 세션 한도와 운영자 교대를 기준으로 정한다. 사람의 채팅 답변을 넣거나 AI 표시를 추가했다고 녹화 반복 금지가 풀렸다고 계산하지 않는다.

공개 녹화 방식이 허용되지 않으면 실시간 사람이 진행하는 방송과 승인된 보조 AI/짧은 증거 영상으로 전환한다. 실시간 AI 형식이 허용돼도 **실시간 제품 별도 평가**가 필요하다. offline HeyGen IV/V·Sync 합격 점수를 실시간 아바타에 옮기지 않는다. 발화/입모양 평가, 음성 시작 지연, 질문 중단·재개, 숫자·상품·조건 검수, 무응답/연결 끊김 fallback을 해당 제품으로 다시 시험한다.

## 6. 관측·사업 평가

| 범주 | 기록할 지표·분모 |
| --- | --- |
| 제작 | 최종 채택한 고유 호스트 분량 U, 총 유료 생성 분량, 재생성 배수 f, 엔진·job별 비용, 인간 검수 시간 |
| 품질 | 음성·입모양 평균/분포, 4/5 채택 의사, 발음·수치·시각 결함 수, 측정 가능한 A/V 기준점 |
| 운영 | 유효하지 않은 장면 차단 수, 위험 정보 감지·차단 시간, 세션/장면 전환·재연결·takeover, 데이터 신선도 |
| 상거래 | 계정에서 제공되는 동일 정의의 시청자 수·상품 클릭·장바구니·주문·거래액·쿠폰 사용. 분모/귀속 기간을 기록 |
| 효과 비교 | 같은 국가·SKU·오퍼·트래픽 조건·시간대에서 순서를 번갈아 비교. 할인이나 광고비 차이를 콘텐츠 효과와 혼동하지 않음 |

클릭률은 계정에서 얻을 수 있는 일관된 시청자 분모로 정의한다. 구매 전환율은 해당 계정의 상품 클릭 또는 유입 정의 중 하나를 고정한다. 원천 데이터가 제공되지 않으면 추정값으로 만든 리포트를 실제 매출 귀속으로 표시하지 않는다.

AL라이브 영어 원본 샘플과 동일 오퍼·같은 조건의 평가 데이터가 없으면 경쟁사 대비 우월을 확정하지 않는다. 현재 확인한 공개 기능, 이번 시스템 합격 목표, 실제 파일럿 수치를 별도 열로 유지한다.

## 7. 실패 전제 검토

1. **얼굴은 예쁘지만 발화가 어색해 이탈한다.** 먼저 170초 시험과 영어 평가를 통과시킨다. 불합격 엔진으로 24편을 대량 생성하지 않는다. 실패 원인이 음성이면 master부터, 입모양이면 해당 엔진/shot부터 수정한다.
2. **가격은 바뀌었는데 녹음은 예전 혜택을 말한다.** 오퍼 버전과 음원 연결, 시작 전 유효시간 검증, active 음성 차단 시험으로 막는다. 배너 수정만으로 음성 검수를 통과시키지 않는다.
3. **내부 24시간 테스트를 통과하고 실제 Shopee에서 제재된다.** 공개 승인을 독립 단계로 두고 계정·국가별 근거를 확인한다. 승인 불가이면 합법적 배치와 실시간 감독 운영으로 범위를 조정한다.

## 8. 종료 조건과 실제 결과 기록

계획 작성은 근거·요구사항·문서 링크·산술 및 독립 Architect→Critic 검토가 끝나면 종료한다. 현재 영상 생성·영어 사용자 평가·24시간 내부 운전·공개 방송은 **미실행**이다.

후속 제작 완료 시 `AC-LIP / AC-FACT / AC-SOAK / AC-LIVE`를 각각 통과·실패·미실행으로 표기하고 결과 파일을 연결한다. 미실행 단계가 남으면 해당 단계의 성공이나 공개 운영 가능성을 주장하지 않는다.
