# 대본 생성 규칙 (AI 쇼호스트 라이브, 영어)

Shopee 11월 3편(V1 프라이머·V2 립앤치크·V3 클렌징밤) 대본(`AI쇼핑라이브_Shopee_202611/0_기획/build_v3_text.py`)과
뷰티 판매 문법(`docs/plan/banila-shopee-ai-live_beauty-grammar_v1.md`)에서 실제로 쓴 구조를 떼어 낸 것입니다.
Claude가 새 제품 대본을 쓸 때 이 순서와 규칙을 따릅니다. 결과는 `brief/script.json`(형식은 `schema/script.example.json`).

## 1. 한 편의 뼈대 (약 7분, 22~30줄)

| 순서 | 장면 ID | 역할 | 화면 유형 | 길이 | POC 예 |
|---|---|---|---|---|---|
| 1 | `OC` | 공통 오프닝 — 브랜드 인사·AI 호스트 고지 | B→H | 20초 | 3편 공통 OC-1~3 |
| 2 | `O-<제품>` | 오늘의 제품 + 혜택 한 줄 | H+G (진열 누끼 + 혜택 배너) | 20초 | "Today it's all about Prime Primer … fifty percent off" |
| 3 | `<P>1` | 고민 공감 (구매 상황) | H 또는 B→H | 20초 | "does your base slide off by lunch?" |
| 4 | `<P>2` | 루틴·오늘의 룩 카드 (제품이 여러 개일 때) | G 또는 G+H | 10~25초 | 루틴 카드 Sun Base → Classic → … |
| 5 | `<P>n-1` | 제품 소개 — 이름 + 한 줄 정체성 | H+G (누끼 확대) | 20초 | "Prime Primer Classic … cream primer" |
| 6 | `<P>n-2…` | 원본 증거 — 제형·사용 장면 | S 또는 D (공식 시연 영상) | 20~30초 | 선베이스 바르는 영상 |
| 7 | `<P>n-3` | 사용 팁 | H | 15~25초 | "one drop … too much can make your base slide" |
| 8 | `<P>n-4` | 사용법 카드 (단계 2~4개) | G | 10초 | pea-size → press → wait → base |
| — | 5~8을 제품 수만큼 반복 | | | | |
| 9 | `<P>7` | 피부 타입·상황별 FAQ | H+G | 30~45초 | 지성/건성 팁, Which balm is for me? |
| 10 | `<P>8` | 혜택 재안내 + 구매 행동 | G+H (혜택 배너) | 20초 | "One more time: … fifty percent off today" |
| 11 | `EC` | 공통 엔딩 → 오프닝으로 루프 | H+G | 30초 | 3편 공통 EC-1~3 |

색조(호수가 많은 제품)는 6~8 대신 **오늘의 룩 → USP ①~⑤ → 호수별 발색 배너(호수당 약 7초 V/O) → 퍼스널컬러 트리오 → 상황별 추천**(V2 구조)을 씁니다.

## 2. 화면 유형 (편집 스크립트가 이 코드로 합성)

| 코드 | 화면 | 소리 | 생성 단위 |
|---|---|---|---|
| H | 호스트 + 헤드라인 + AI 고지 + 자막 | 호스트(H3) | h3 |
| H+G | H + 측면 카드(누끼·짧은 문구) | 호스트(H3) | h3 |
| S | H + 하단 시연 창(공식 영상, 원본 소리 제거) | 호스트(H3) | h3 |
| G | 전체 화면 카드 | V/O(T2A) | vo |
| G+H | 전체 화면 카드 | 호스트 음성 | h3 |
| D | 공식 시연 영상 전체 화면 | V/O(T2A) | vo |
| B→H | 분위기 컷 → 호스트 | 호스트(H3) | h3 |

대사 앞에 `V/O:`를 붙이면 화면 밖 목소리(vo)로 만듭니다.

## 3. 문장 규칙

- 한 문장 7~14단어, 한 문장에 정보 하나. 호스트 줄은 **30단어 이하**(15초 클립 1개, 1.25배속 기준 초당 약 2.4단어).
- 숫자·단위는 말하는 형태로 풀어 씀: `100 mL` → "one hundred milliliters". 화면 표기는 카드에서 따로.
- 제품명은 Product Spec의 영문 정식명. 문서에 영문명이 없으면 `[확인 필요]`로 두고 지어내지 않음.
- 가격·할인율·사은품·기간은 `intake.json`의 promo 값만. 비어 있으면 "today's offer"처럼 숫자 없이.
- 호스트가 써 본 것처럼 말하지 않음("I tried this" 금지). 실시간 질문을 꾸미지 않음("Someone just asked" 금지).
- 재고·마감 긴박감은 확인된 사실일 때만.

## 4. 근거 표시 (줄마다 `basis`)

- `Product Spec v<N>` / `공식몰 (조회일)` / `NAS 시연 영상 <파일명>` 중 하나 이상. 근거 없는 줄은 쓰지 않음.
- 문서에 있어도 쓰지 않는 것: 시험 수치(%·시간), 판매 순위·"bestseller", 임상·피부과, 치료·예방·미백·주름·모공 축소·여드름 같은 효능.
  → "looks smoother", "feels fresh", "pores look less visible"처럼 **외관·사용감**으로 낮추고 `ra: true`.
- 경계가 애매하면 더 보수적으로 쓰고 `ra: true` + `note`에 원문 표현을 남김 (RA/법무 사전검토 대상).

## 5. 시연 소스 배정 (`source`)

- S·D 줄에는 NAS에서 받은 영상 파일 키(`assets_manifest.json`의 key)와 사용 구간(in/out초)을 적음.
- 영상이 없으면 `source: null` + `note: "시연 영상 없음 — 누끼 카드로 대체"`. 시연을 약속하는 대사는 쓰지 않음.
- 번인 자막·수치가 박힌 영상은 육안 확인 전까지 `check: "번인 확인"`.

## 6. 손 동작 (`gesture`, 호스트 줄만)

H3 프롬프트에 그대로 들어갑니다. POC에서 쓴 것: 손 모아 시작 / 한쪽 손바닥으로 옆 소개 / 검지 하나 들기 / 가볍게 손 흔들기 / 아래 오른쪽 가리키기(시연 창 쪽).
제품을 손에 들거나 바르는 동작은 넣지 않음(손·패키지 변형 방지).
