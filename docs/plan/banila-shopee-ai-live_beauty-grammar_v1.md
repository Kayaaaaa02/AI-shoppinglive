# 바닐라코 Shopee 영어 AI 방송: 뷰티 판매 문법 v1

작성일: 2026-10-02. 목적: 프로모션과 구성 혜택을 영어 AI 호스트로 전달하고, 제품 시연과 사용감의 근거는 브랜드 원본으로 보여주는 제작 기준.

**핵심 문법: 구매 상황 → 구체적인 구성 혜택 → 원본 증거 → 적용 조건 → 구매 행동 → 짧은 재안내.** 시청자가 어느 지점에 들어와도 상품, 혜택, 조건, 구매 위치를 이해할 수 있게 만든다.

이 문서의 시간·화면 비율·대본은 제작 제안이며 실측 결과가 아니다. 녹화 콘텐츠 제작과 Shopee Live 공개 송출 허용은 별개다. 국가·계정별 허용 형식 확인 후 방송에 적용한다. [국가별 공식 정책 조사](../review/shopee-ai-live_policy_research_v1.md)를 함께 읽는다.

채택할 기준은 감도, 검증된 표현, 작은 장면, 선택 도움이다. PDF의 품절을 구매 신호로 활용하는 제안은 사실에 근거한 재고 안내로 한정한다. 실제 품절을 판매 가능처럼 보여주거나 인위적으로 품절·마감을 만들어내지 않는다.

## 2. 역할 분담

| 요소 | AI 호스트가 맡을 내용 | 원본·데이터·운영자가 맡을 내용 |
| --- | --- | --- |
| 오프닝 | 영어 인사, 구매 상황, 이번 장면의 선택 기준 | 국가·세션·현재 판매 SKU 확인 |
| 혜택 | 승인된 구성, 단품과 묶음의 차이, 쿠폰 적용 순서 설명 | 실제 가격, 최소 결제금액, 할인 상한, 중복 적용 여부, 기간, 수량 |
| 상품 증거 | 원본 장면을 소개하는 짧은 연결 멘트 | 브랜드 승인 시연, 발색, 텍스처, 사용법, 필요한 시험 조건 |
| 질문 | 검증된 일반 FAQ. 실시간 질문 연결은 허용된 운영 경로에서 실제 질문이 있을 때만 | 모더레이터가 실제 질문을 확인하고 공식 답변/개인 상담으로 연결 |
| 구매 안내 | 현재 노출된 상품 카드를 여는 행동 안내 | 실제 Shopee 상품 pin, 쿠폰, 옵션, 판매 가능 상태 |
| 브랜드 표현 | 사실 확인된 브랜드 설명, AI 진행자임을 알리는 표현 | 국가·계정별 AI 표시 형식, 상표·모델·음성·음악 사용 권리 |

AI 얼굴에 제품을 바르게 하거나 용기를 손에 쥐게 하는 연출은 초기 파일럿에 넣지 않는다. 얼굴·입 주변의 가림, 손·패키지 변형, 실제 사용 경험으로 받아들여질 표현을 줄이고 발화 품질 검증에 집중한다. 제품 팩샷과 증거 영상은 별도 화면으로 배치한다.

## 3. 중간 유입을 위한 90초 판매 단위

제안: 6분 에피소드 한 편을 서로 이해 가능한 90초 단위 네 개로 구성한다. 각 단위는 다른 판매 질문을 다루되 상품명과 행동 안내를 다시 제공한다. 라이브에서의 반복 허용 여부는 별도 정책 조건이다.

| 구간 | 역할 | 영어 표현 예시 | 화면·데이터 조건 |
| --- | --- | --- | --- |
| 0-6초 | 구매 상황과 상품 식별 | “Looking for a Banila Co set? Let’s check what’s included.” | 실제 세트가 있을 때만 사용. AI 호스트와 정확한 상품명 |
| 6-21초 | 구성과 선택 이점 | “This set includes [ITEM_A] and [ITEM_B]. Here are the sizes.” | 승인된 SKU·용량. 가격/할인 데이터와 분리 가능한 상시 멘트 |
| 21-36초 | 단품·묶음 선택 | “Choose the option that matches what you need.” | 상품 옵션과 단품/묶음 카드. 절감액은 동일 조건으로 계산 가능한 경우에만 |
| 36-51초 | 원본 증거 | “Here’s the brand’s original product demonstration.” | 승인된 원본만 사용. 시연 사전 녹화 허용 길이·형식 확인. 원본의 피부·색·전후 결과 보존 |
| 51-71초 | 혜택 적용 방법 | “Open the voucher terms and check the minimum spend before checkout.” | 해당 계정에서 실제 사용 가능한 쿠폰이 있는 경우. 최소금액·상한·기간 표시 |
| 71-83초 | 구매 방해 질문 해소 | “For the full list of items, check the product card.” | 공식 구성과 카드 일치. 배송은 국가·주소·주문 조건에 맞는 정보만 |
| 83-90초 | 한 번의 행동 요청 | “Open the product card, choose your option, and check the final total.” | 운영자가 확인한 실제 상품 카드. 클릭 불가능한 가짜 버튼을 만들지 않음 |

위 문구는 템플릿이다. `[ITEM_A]` 같은 필드가 남으면 렌더링 및 송출을 차단한다. 원본 영상이 미확보이거나 삽입 불가한 경우 36-51초는 승인된 제품 팩샷과 구성 설명으로 대체하고 시연을 약속하지 않는다.

얼굴을 계속 띄우는 것보다 문장 전달과 쇼핑 선택이 명확한 화면을 목표로 한다. 초기 편집 배분 제안은 혜택·구성·거래 안내 60%, 원본 증거 20%, 사실 기반 FAQ·브랜드 설명 20%. 이는 화면 편집 시간의 비율이며 얼굴이 보이는 시간의 비율과 다르다.

## 4. 혜택을 설명하는 여섯 가지 문법

| 판매 목적 | 문법 | 사실 확인할 필드 |
| --- | --- | --- |
| 첫 구매 | 무엇을 사는지 → 구성품 → 선택 기준 → 최종 결제 확인 | 첫 구매 전용 혜택이 실제 있는지, 대상 조건 |
| 묶음 비교 | 같은 상품·용량·옵션 조건 → 단품 합계 → 묶음 결제 → 차이 | 비교 기준시점, 쿠폰 포함 여부, 배송료, 반올림, 실제 구매 가능 옵션 |
| 증정품 | 구매 조건 → 증정품 이름·용량·수량 → 적용 방식 | 선착순·재고·소진 시 정책·결제금액 기준. 모든 주문에 자동 증정이라고 추정하지 않음 |
| 쿠폰 | 쿠폰 종류 → 받는 위치 → 최소금액 → 상한 → 유효기간 | 계정 노출, 중복 적용, 주문별 제한, 특정 결제수단·배송 조건 |
| 선물/휴대 | 실제 구성 → 용도 선택 → 포장·배송 옵션 | 판매 중인 미니/트래블 구성, 선물 포장 제공 여부 |
| 캠페인 마감 | 실제 종료시각·현지 시간대 → 적용 조건 → 구매 안내 | 서버 시간·캠페인 버전. 순환되는 가짜 카운트다운 금지 |

혜택이 확인되지 않은 장면은 일반 상품 선택 안내로 낮추거나 편성에서 제외한다. AI가 빈 필드를 추측해서 채우지 않는다.

## 5. 자연스러운 영어 발화를 위한 대본 규칙

- 문장당 7-14단어를 초안 기준으로 삼고, 한 문장에 한 정보를 담는다. 혜택 조건이 많으면 화면에서 나눠 설명한다.
- 기본 말속도는 분당 135-150단어, 숫자·조건 구간은 125-140단어를 초기 테스트 범위로 삼는다. 최종 속도는 목표 시장 영어 사용자 평가로 결정한다.
- 제품·브랜드 발음 사전에 Banila Co, Clean It Zero, Covericious, milliliters, voucher, minimum spend, 통화명과 SKU명을 넣는다. 브랜드 승인 발음과 목표 시장 검수 후 고정한다.
- 화면은 `100 mL`처럼 읽기 편하게, 발화용 대본은 `one hundred milliliters`처럼 풀어 쓴다. 두 표현은 같은 필드에서 생성하고 검수한다.
- 혜택 직전에 짧게 숨을 쉬고, 쿠폰 조건 끝에 작은 쉼을 둔다. 강조는 핵심 구성·할인·행동 하나에 둔다.
- 한 호스트에 한 승인 음성을 기본으로 유지한다. 영상마다 강세·억양·속도가 바뀌지 않게 음성 설정과 버전을 저장한다.
- 완성 음성에 맞춰 입모양을 생성한다. 립싱크 완료 후 오디오만 빨라지게 하거나 다른 음성으로 교체하지 않는다.
- 고립된 2초 입모양을 반복해 긴 발화를 만들지 않는다. 말의 앞뒤 호흡과 표정까지 평가한다.

### 영어 발화 검증용 문장

아래 수치와 프로모션은 **시험용 가상 조건**이다. 공개 콘텐츠에 그대로 사용하지 않는다.

1. “Welcome to Banila Co. Let’s take a closer look at Clean It Zero.” — 브랜드·제품명.
2. “This sample set includes two jars and one mini.” — 구성 수량, /m/·/p/·/b/ 계열 입모양.
3. “One hundred milliliters. Please check the size on the product card.” — 단위와 분절.
4. “Save fifteen percent, up to one hundred pesos, on orders over five hundred pesos.” — 할인율·상한·최소금액. PH 가정 시험.
5. “Before you pay, check the voucher terms and the final total.” — /f/·/v/·/t/ 발화와 조건 강조.
6. “Thanks for joining. Choose your option in the product card.” — 웃는 표정에서 입모양, 문장 끝 자연스러움.

음성 비교는 먼저 같은 대본으로 수행한다. 립싱크 엔진 비교에는 확정된 동일 음성 파일을 사용한다. 검증용 과장된 혜택 문구와 실제 판매 대본을 분리한다.

## 6. 표현 검수: 허용 사실과 만들어낸 경험 구분

| 피할 표현·연출 | 이유 | 제작에 쓸 표현·처리 |
| --- | --- | --- |
| “I tried this, and my skin feels amazing.” | AI의 실제 사용 경험을 꾸며냄 | 제품의 확인된 구성·사용법 또는 승인된 실제 사용자 인용으로 바꿈 |
| “It works for every skin type.” | 원본/현지 승인 없이 보편 효과·안전 약속 | 공식 상품 설명에서 확인된 표현만 사용. 필요한 경우 전체 성분·사용법 확인 안내 |
| “Only three left!” | 재고가 검증되지 않으면 허위 긴급성 | 확인된 판매 가능 상태. 재고 신뢰도가 떨어지면 수량 발화를 생략 |
| “Shipping is free for everyone.” | 주소·쿠폰·계정·결제 조건이 다를 수 있음 | 승인된 배송 혜택의 정확한 대상·조건을 표시하거나 결제 화면 확인 안내 |
| “Someone just asked about shipping.” | 실제 질문이 없는 녹화에서 가짜 실시간 반응 | 일반 FAQ는 “Here’s a quick note about delivery.” 실제 질문 연결은 허용 경로에서 확인 후 |
| AI 생성 비포애프터, 피부 톤을 바꾼 원본 | 생성/보정된 결과를 상품 효과로 오인 | 원본 결과 유지, 비교 조건·관련 표기 유지. 제품 증거용 피부/색상 보정 금지 |
| 미국 달러/한국 원화 할인율을 PH/SG 혜택으로 번역 | 동일 국가 상품·가격·조건이 아님 | 해당 storefront의 확인된 SKU와 혜택 스냅샷에서 새로 작성 |

현지 효능 표현의 허용 여부는 원문 출처가 있다고 자동 보장되지 않는다. 국가별로 승인된 문구 목록과 원본 버전을 연결한다. AI 표시 역시 녹화 반복 제한을 해소하는 근거가 아니다.

## 7. 장면별 제작 카드

각 장면에 다음을 기록한다. 영어 문구만 저장하면 가격·원본·승인 조건이 바뀔 때 안전하게 재사용할 수 없다.

| 필드 | 기록 내용 |
| --- | --- |
| 목적·언어·국가 | 첫 구매/묶음/쿠폰/FAQ, 영어, 목표 storefront |
| 상품·옵션 | SKU, 상품 카드 ID, 용량·색상·구성품, 판매 가능 조건 |
| 혜택 | offer ID/version, 통화, 가격, 쿠폰 조건, 유효시간·현지 시간대 |
| 영어 대본·발음 | 발화용·자막용 대본, 승인 발음 사전 버전 |
| 원본 증거 | source ID, 원본 파일·시작/종료시각, 승인 claim ID, 필요한 주석 |
| 제작·검수 | 호스트/음성/엔진 버전, 음성 해시, 렌더 파일, 영어/원본/혜택 검수자 |
| 공개 사용 조건 | 국가·계정·형식 승인, 사용 권리·기간, 승인 완료 여부 |
| 수정 영향 | 가격만 바뀌면 카드 교체 가능한지, 발화도 바뀌면 어떤 장면을 재생성할지 |

현재 체크아웃의 [POC 제품 정보](../../SRC/data/POC_product_info/POC_제품정보.md:261)는 클렌징밤과 색조 자료 탐색에 쓸 인덱스다. 해당 폴더에는 실제 미디어 파일이 없고, 정보는 KR/US 기준이다. 이를 원본 확보 완료나 SEA 프로모션 승인으로 해석하지 않는다.

## 8. 제작 승인 기준

완성 장면은 영어 발화·입모양·얼굴 일관성, 실제 상품/조건 일치, 원본 증거 보존, 구매 위치의 일치, 사용 권리가 모두 확인돼야 제작 승인 상태로 올린다. 공개 송출에는 국가·계정·형식·상호작용·연동 승인 조건이 추가로 필요하다.

자세한 평가 방법과 합격 목표는 [검증 명세](banila-shopee-ai-live_test-spec_v1.md)에 정의한다. 제작 승인과 송출 승인을 다른 상태로 관리하는 것이 이 문법의 마지막 규칙이다.
